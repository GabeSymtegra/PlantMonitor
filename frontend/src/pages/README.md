# Frontend Pages

Pages are route-level screens.

## Current Screens

- `Dashboard.tsx`: live production overview
- `StatusBoard.tsx`: simplified monitoring display
- `Lines.tsx`: line listing and status filtering
- `LineDetails.tsx`: single-line runtime details
- `Reports.tsx`: completed runs and runtime event history
- `Administration.tsx`: configuration and PLC administration
- `Settings.tsx`: application settings
- `Login.tsx`: sign-in screen
- `Forbidden.tsx`: authorization failure screen
