# Frontend Source Layout

This folder contains the React application source.

## Main Areas

- `components/`: reusable UI building blocks
- `context/`: application-wide state and providers
- `layouts/`: structural shells such as the app frame
- `models/`: TypeScript models used by the UI
- `pages/`: route-level screens
- `routes/`: router definitions and guards
- `services/`: API and data access
- `theme/`: theme configuration
- `types/`: shared UI-facing type declarations
- `utils/`: formatting and helper utilities

Entry points:

- `main.tsx`: app bootstrap
- `App.tsx`: root component
